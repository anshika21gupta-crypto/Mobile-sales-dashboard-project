# Mobile-sales-dashboard-project
An interactive, multi-page Power BI analytics solution developed to track mobile retail performance, evaluate multi-year revenue growth, and analyze consumer purchasing patterns across Indian retail markets.  
Project Overview
This project focuses on transforming raw transactional data into actionable business intelligence for retail operations. It combines high-level executive KPI monitoring with granular exploratory analysis, enabling stakeholders to assess sales trajectories across time periods, regions, brands, and payment methods.

🚀 Key Features
Executive Overview (Main Dashboard):

Core KPI Cards: Total Sales (769M), Total Units Sold (19K), Total Transactions (4K), and Average Selling Price (40.11K).

Geo-spatial distribution of revenue across major Indian metros (Delhi, Mumbai, Bengaluru, Chennai, etc.).

Brand & Model benchmarking (Apple, OnePlus, Samsung, Vivo, Xiaomi) comparing revenue vs. units sold.

Payment method distribution (UPI, Credit Card, Debit Card, Cash) and customer rating breakdowns.

Advanced Time Intelligence Modules:

MTD Report: Tracks daily cumulative month-to-date revenue against target milestones.

QTD Report: Monitors quarter-to-date sales curves alongside quarterly aggregate tables.

YTD Report: Analyzes multi-year year-to-date trajectory and cumulative performance across financial cycles (2021–2024).

Same Period Last Year (SPLY): Side-by-side YoY comparative analysis (quarterly and monthly bars) to evaluate period-over-period growth.

Interactive User Experience:

Custom page navigation system with responsive button bookmarks.

Multi-dimensional filtering by Brand, Mobile Model, Payment Method, Year, and Month.

🛠️ Tech Stack & Skills
BI Platform: Microsoft Power BI Desktop

Data Transformation: Power Query (ETL, schema shaping, type normalization)

Data Modeling: Star Schema design, Date table creation, custom relationships

Calculations: DAX (Data Analysis Expressions)

Cumulative running totals (TOTALMTD, TOTALQTD, TOTALYTD)

Shifted period comparisons (SAMEPERIODLASTYEAR, CALCULATE)

Dynamic measure aggregations (DIVIDE, AVERAGE, COUNTROWS)
